Configuração do Firebase

Siga os passos abaixo para ativar o login e o armazenamento na nuvem.
Leva cerca de 15 minutos e é totalmente gratuito.

1 Criar o projeto no Firebase
  1. Acesse console.firebase.google.com
  2. Clique em "Criar um projeto"
  3. Dê um nome (ex: estudo-biblico) e clique em Continuar
  4. Desative o Google Analytics → Clique em Criar projeto
  5. Aguarde a criação → Clique em Continuar
2 Ativar o Login com Google
  1. No menu lateral, clique em Authentication
  2. Clique em Começar
  3. Na aba Sign-in method, clique em Google
  4. Ative o botão no canto superior → selecione seu e-mail → Salvar
3 Criar o banco de dados (Firestore)
  1. No menu lateral, clique em Firestore Database
  2. Clique em Criar banco de dados
  3. Escolha "Começar no modo de produção" → Avançar
  4. Escolha a região us-east1 → Criar
  5. Na aba Regras, substitua tudo por:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/studies/{studyId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

Clique em Publicar para salvar as regras.

4 Copiar as chaves para este arquivo
  1. No Firebase, clique em ⚙️ Configurações do projeto (ícone de engrenagem)
  2. Role até "Seus apps" → Clique no ícone </> (Web app)
  3. Digite um apelido (ex: estudo-web) → Registrar app
  4. Você verá o bloco firebaseConfig com seus valores
  5. Abra estudo-biblico-online.html no Bloco de Notas
  6. Encontre a seção abaixo e substitua cada valor:
const firebaseConfig = {
  apiKey:            "COLE_SEU_API_KEY_AQUI",
  authDomain:        "COLE_SEU_AUTH_DOMAIN_AQUI",
  projectId:         "COLE_SEU_PROJECT_ID_AQUI",
  storageBucket:     "COLE_SEU_STORAGE_BUCKET_AQUI",
  messagingSenderId: "COLE_SEU_MESSAGING_SENDER_ID_AQUI",
  appId:             "COLE_SEU_APP_ID_AQUI"
};

Salve o arquivo (Ctrl+S) e reabra no navegador.

5 Publicar online (Netlify — gratuito)
  1. Acesse netlify.com → Sign up com Google
  2. Na tela inicial, arraste o arquivo estudo-biblico-online.html para a área cinza
  3. Aguarde o upload — o Netlify gera uma URL automática
  4. Copie a URL (ex: seu-app.netlify.app)
  5. No Firebase → Authentication → Configurações → Domínios autorizados
  6. Clique em Adicionar domínio e cole o domínio do Netlify (sem https://)

Após configurar as chaves e salvar o arquivo, reabra-o no navegador.
